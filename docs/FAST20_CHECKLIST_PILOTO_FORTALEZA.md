# FAST-20 - Checklist Piloto Fortaleza

## Smoke Web
- abre Home;
- cria/recupera perfil;
- Mapa de Fortaleza abre;
- seis zonas visiveis;
- Zona 7 ausente;
- Duelo das Placas abre;
- Construa o Bairro abre;
- Progressao Global abre;
- Meu Progresso abre;
- Dashboard Pedagogico abre;
- Faixita abre em modo local;
- scroll sem congelamento;
- reload preserva progresso.

## Smoke Android
- instala APK;
- abre sem crash;
- perfil persiste;
- progresso persiste;
- modo aviao mantem jornada local;
- Faixita local responde;
- fechar e reabrir preserva dados.

## Restricoes conhecidas
- assinatura Android de piloto usa debug key;
- backend pedagogico HML ainda nao publicado;
- Faixita remota HML ainda nao publicada;
- publicacao em loja nao faz parte deste piloto.
